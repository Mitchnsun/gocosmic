# Mini Glossary (FR -> EN)

| Français (terme métier) | English (canonical term)   | Usage note                                    |
| ----------------------- | -------------------------- | --------------------------------------------- |
| prospect                | lead                       | Potential client before qualification         |
| client                  | client                     | Paying customer                               |
| devis                   | quote                      | Commercial proposal sent before project start |
| offre                   | service package            | Structured service bundle (solo/team/duo)     |
| accompagnement          | support                    | Ongoing guidance during or after delivery     |
| vitrine (site vitrine)  | marketing website          | Non-transactional presentation website        |
| application mobile      | mobile app                 | Mobile product deliverable                    |
| abonnement              | subscription plan          | Recurring service pricing                     |
| taux journalier         | daily rate                 | Billing model per day                         |
| mise en production      | production release         | Deployment to live environment                |
| cahier des charges      | requirements specification | Functional and technical project scope        |
| recette                 | acceptance testing         | Validation before production release          |
